# 股票 picker

## 描述

从每日财经新闻中系统性挖掘具有短期或中期交易机会的个股，输出结构化的选股分析报告。与日报生成模块分离，专职负责选股任务。

## 使用场景

- 每日股市日报需要附带"精选个股"板块
- 从海量快讯中不遗漏任何被提及的股票机会
- 对个股进行量化评分（强度 1-5 星）和周期标记（短线/中线/长线）

## 核心 Prompt

### System Prompt

```
你是一位资深量化选股分析师，擅长从海量财经新闻中系统性挖掘具有短期或中期交易机会的个股。你需要全面扫描所有新闻，不遗漏任何被明确提及的股票。输出必须结构化、量化、可执行，对每只股票的判断必须有新闻依据，严禁编造。
```

### User Prompt 模板

```
请基于以下今日股市新闻，执行系统性选股分析。

任务要求：
1. **全面扫描**：仔细阅读每一条新闻，找出所有被明确提及的股票（包括股票名称、代码）。
2. **分类标记**：
   - 🔥 强势利好：业绩大增、重大合同、政策扶持、技术突破、并购重组
   - ⚡ 事件驱动：行业会议、产品发布、订单公告、获机构调研
   - ⚠️ 利空风险：业绩下滑、监管处罚、减持、安全事故、诉讼
3. **量化评分**：对每只利好股给出机会强度（⭐1-5星）和关注周期（短线/中线/长线）
4. **输出格式**：
   - 先输出 "📈 精选个股" 板块，用 Markdown 表格：股票名称代码 | 利好类型 | 核心催化因素 | 强度 | 周期 | 风险提示
   - 再输出 "⚠️ 今日避雷" 板块，同样用表格列出有明显利空的股票


注意：
- 即使某只股票只被提及一次，只要逻辑成立也应列出
- 不要编造没有新闻支撑的股票
- 每个新闻下的精选个股数量不少于 3 只，不多于 12 只

---
今日新闻数据：

{news_text}
```

## 技术参数

| 参数 | 值 | 说明 |
|:---:|:---|:---|
| 模型 | `deepseek-v4-pro` | 与日报共用同一模型 |
| temperature | 0.3 | 比日报更低，确保选股更客观严谨 |
| max_tokens | 4096 | 保证能输出完整的选股表格 |
| 超时 | 120 秒 | 与日报一致 |

## 集成方式

在 `stock_report.py` 的 `main()` 流程中：

1. 先调用 `call_llm()` 生成日报
2. 再调用 `call_stock_picker()` 生成选股结果
3. 用 `format_stock_picks()` 格式化后追加到日报末尾

```python
report = call_llm(news_text)
stock_picks = call_stock_picker(news_text)
if stock_picks:
    report += format_stock_picks(stock_picks)
```

## 迭代建议

- **增加量化数据输入**：后续可接入东方财富涨幅榜、资金流向数据，让 LLM 在选股时同时参考量价信息
- **建立股票池跟踪**：维护一个"持续关注股票池"，每次选股时对比历史推荐，评估胜率
- **分级推送**：将 ⭐⭐⭐⭐⭐ 级别的股票单独推送到微信，其他只在网页版展示
