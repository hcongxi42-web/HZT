# 2026-09-07 工作日志

## 盘面分析（analyst）思考过程泄漏加固
用户贴出 9/7 盘面+AI选股输出，发现**思考过程泄漏**不仅出现在 AI选股，也出现在盘面分析与研判（"就说偏暖吧""用「偏暖」""不纠结""不提""需要确认的是"等独白 + 复述结构清单"今日要点5行/资金面"）。

根因：9/4 只给 AI选股加了 `_sanitize_stock_picks`，盘面段无等效防护；`system_analyst.txt` 仅有软性禁用词，且 `_strip_thinking` 词表未覆盖盘面式口语独白。

改动：
- `prompts/system_analyst.txt` + `user_analyst.txt`：加【硬性语法约束】——推理模型声明、正文仅允许 `## `/`- **`/列表 三种语法、禁自问独白/复述结构清单/决策犹豫；`user_analyst.txt` 增"明天=下一交易日"说明。
- `stock_report.py`：
  - `_strip_thinking` 扩词表（就说/用「/需要确认的是/不纠结/不提/我倾向/如果落实到投资/为了表格/不过用户/用户严格要求/注意是/再看资金面/具体各大行的/温度判断 等）。
  - 新增 `_sanitize_analyst()`：以首个 `- **`/`## `/编号/`今日要点：`/`市场体温：` 为锚点丢弃其前全部（含结构清单+前置独白）；逐行删自问句（保守词表：用哪个/加不加息/算什么/按什么/该不该/要不要）与元评论行；带 `- **` 标签要点与标题一律保留。
  - `call_llm`（即盘面分析，旧名 call_analyst）套 `_sanitize_analyst` 且 `max_tokens` 4096→6000。

验证：`_test_analyst_sanitize.py` 模拟泄漏草稿 → 锚定生效、独白与清单全剔除、真实内容（资金面/主线扫描编号/情景概率/要闻标签）保留；干净成品不被误伤（含带问句的"最大分歧"要点保留）。已删除临时脚本，模块编译通过。

待办：本地改动仍需能连 GitHub 的代理 `git push` 覆盖 CI 旧代码（CI 仍跑泄漏版）。AI选股侧 `_sanitize_stock_picks` 已能在部署后拦截纯草稿（无 ###/表格→降级文案）。
