## 从投资者视角评审 HZT 项目「可增加项」

- 背景：用户问"从投资者角度，项目还有什么可以增加的地方"。
- 方法：先摸清四路模块边界（读 prompts/ 8 个模板 + SETUP_GUIDE.md），再按投资者决策闭环（感知→判断→执行→复盘）做缺口分析。
- 结论：感知/判断两环已强（盘面、信息差、UP主蒸馏、要点、评级、情景概率）；**执行与复盘两环空白**——这是最大增量空间。
- 提出的可增加方向（按杠杆排序）：
  1. 🔴 复盘闭环/战绩追踪（选股落盘 json → 次日算涨跌幅/超额/胜率 → 模拟组合净值曲线）——最高杠杆，且与用户量化论文的 IC/回测方法论同源。
  2. 🟠 可操作性：每行补关注价位/止损/建议仓位；盘面加关键支撑压力位；情景概率补"触发条件"。
  3. 🟡 硬数据面板：涨跌家数、涨停/跌停、成交额环比、北向/主力净流入、两融、指数 PE/PB 分位（用东方财富 push2 接口，stdlib 可拉）。
  4. 🟢 事件日历/催化剂：未来 3-5 交易日财报、解禁、IPO、会议/数据。
  5. 🔵 个性化：watchlist 自选股/持仓诊断，从泛市场简报升级为持仓仪表盘。
  6. 🟣 时间聚合+分发：周/月总结、晨报一句话摘要推送（复用已有 Server酱/Webhook）。
- 约束提醒：项目仅依赖 Python 标准库；上述新增需走公开 HTTP 接口（东方财富等），可行且不破坏现有架构。
