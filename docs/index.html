资金面

主线扫描

国产存储/半导体：SK海力士创纪录 IPO 叠加美股存储板块大涨，半年度业绩预告中「兆易创新」等大幅预增。这是业绩 + 海外映射共振，持续性看量能能否维持，今早肯定是情绪高点。

明天怎么看

情景一（概率较高）：科技强势震荡，存储和算力早盘冲高后有获利盘兑现，指数收小阳线或十字星，其他板块开始轮动补涨。
情景二（有业绩助力）：中报预增逻辑扩散，周期和资源股跟上来，大盘放量站稳整数关口，那反弹空间打开，仓位可激进。
情景三（小概率黑天鹅）：如果盘中 GJD 突然砸大金融降温，或者外围突发利空，指数回踩昨天低点，科技股出现大面，就把仓位降下来。
