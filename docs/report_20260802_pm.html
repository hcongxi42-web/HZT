盘中情报 2026.08.02

资金面

主力在防守，不是进攻。本周沪指勉强红，深成指和创业板指都是跌的，尤其创业板跌了近4%，钱从高估值成长股往外流。场内资金在做高低切，往低估值和事件驱动的方向拱，进攻意愿很弱。

主线扫描

造船链：「恒力重工」单月接单超300亿，这数据很炸。逻辑是行业高景气度的确认，不是讲故事。航运脱碳换船周期没走完，这方向有业绩支撑，持续性会好于纯题材。
存储芯片：央视直接喊出“从周期品走向成长主线”，这是给「AI改写存储周期」的逻辑官方背书。但要注意，申万也说了，AI大波段重启需要时间，别追高，跌下来才是机会。
集采落地：「科伦药业」14款产品拟中标。利空出尽是利好，仿制药的压制因素阶段性解除。这个方向是防守反击的思路，资金避险时会多看一眼。
新能源车分化：「理想」月销3万+，但广汽本田这种合资厂都开始推本土化电车了，说明行业卷得厉害。整车只看有销量支撑的头部，别碰杂毛。
影视消费：「年会不能停！2」8000万票房。暑期档有戏，影视院线方向还能看看，但这属于事件驱动，手脚要快。

跨市场

美股那边有个事很扯，特朗普的帖文要给人付费抢先看，一个月10万美金。这消息会加剧华尔街对“信息不公平”的担忧，如果量化基金靠这个割韭菜，会放大美股波动。对A股的传导路径是，如果美股波动加大，外资风险偏好一降，A股核心资产会承压。港股没明显异动，但「联想集团」被纳入金股，对AI端侧有点情绪支撑。

市场体温

偏冷。逻辑很简单：一则，周末消息面太碎，没有能凝聚共识的强利好。地缘冲突看似缓和，但伊朗和以色列还在过招，资金不敢放开手脚。二则，包钢事故、湘财被查、青岛火灾这种利空一股脑出来，对市场信心是压制。三则，盘面结构就是防守，主力在找低位的船、药，不愿意追高科技，成交量和赚钱效应都上不去。

明天怎么看

情形一，【大概率】延续震荡分化。地缘没继续恶化，央妈AI的导向和造船的强数据，让市场在结构上找到点事干。指数预计低开或平开后窄幅震荡，资金继续在造船、医药、存储里面打转，创业板能否企稳是关键。

情形二，【小概率】地缘冲突超预期恶化。伊朗和以色列谁再发个狠话，大家一起买单。这个情况下啥逻辑都别信，直接降仓位，黄金和油服可能会有个短线脉冲，但是刀口舔血。

情形三，【观察】外资大幅回流。这个是观察点。如果美股因为特朗普收费这事闹情绪，外资可能阶段性更青睐A股避险。如果北向明天开盘就持续流入，那说明有戏，可以跟着外资的偏好去摸一把超跌的核心资产。否则，就安心守着防守品种。
